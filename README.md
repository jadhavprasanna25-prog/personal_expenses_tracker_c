 Personal Expenses Tracker (C)

A simple command-line expense tracker written in C. It records daily expenses and calculates total spending.

## Features
- Add expenses
- View all expenses
- Calculate total spending
- Menu-driven interface

## How to Run

*Requirements:* a C compiler such as GCC.

```bash
git clone https://github.com/jadhavprasanna25-prog/personal_expenses_tracker_c.git
cd personal_expenses_tracker_c
gcc main.c -o main
```
Run it:
- Windows: `.\main`
- Linux/Mac: `./main`
